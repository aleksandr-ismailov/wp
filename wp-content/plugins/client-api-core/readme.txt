Core API functionality for headless WordPress client applications.

== Description ==

Client API Core provides essential REST API endpoints for headless WordPress applications. This plugin enables seamless integration between WordPress backend and modern frontend frameworks.

== Features ==

* Custom REST API endpoints for page content
* Support for custom blocks and form settings
* SEO meta data integration
* Sidebar content management

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/client-api-core/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.

== Frequently Asked Questions ==

= What WordPress version is required? =

WordPress 5.0 or higher is required.

= What PHP version is required? =

PHP 7.4 or higher is required.
